## 🚀 Featured Project

### ⚡ GeoVolt – Electric Vehicle Charging Station Analysis

GeoVolt is a GIS-based web application designed to analyze electric vehicle charging stations and support data-driven location planning.

The project combines interactive mapping, spatial data management and artificial intelligence to help identify suitable areas for new charging stations.

**Key Features**

- 🗺️ Interactive charging station map
- 📍 Location-based station visualization
- 🔎 Filtering and searching charging stations
- ✏️ Point, line and polygon drawing tools
- 📐 Spatial intersection and proximity analysis
- ⚡ Charging station occupancy and availability tracking
- 📊 Energy consumption and usage statistics
- 🤖 AI-assisted charging station location recommendations
- 🗄️ Geographic data management with PostgreSQL and PostGIS
- 🔐 Secure user authentication

**Built with**

`React` • `JavaScript` • `ASP.NET Core` • `PostgreSQL` • `PostGIS` • `OpenLayers` • `Entity Framework Core`
